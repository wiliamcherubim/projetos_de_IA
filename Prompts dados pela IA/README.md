# 🎯 Plano de Estudos de 30 Dias: Qualidade de Software (QA)

Bem-vindo ao repositório do seu **Plano de Estudos de 30 Dias em Quality Assurance (QA)**. Este guia foi projetado para orientar sua transição e consolidação prática na área de QA, abrangendo desde a base conceitual e metodologias ágeis até testes de API e automação Web moderna com Playwright.

---

## 📌 Objetivo do Plano

> **Meta:** Migrar e consolidar conhecimentos práticos na área de Quality Assurance (QA), dominando os conceitos fundamentais de testes de software, a dinâmica de trabalho em metodologias ágeis (Scrum/Kanban), a escrita de casos de teste, o reporte de falhas, a validação de APIs REST com Postman e a introdução à automação de testes Web E2E com Playwright.

Ao término deste ciclo de 30 dias, você estará apto a atuar em equipes de tecnologia garantindo a qualidade manual e automatizada do produto.

---

## 🗺️ Visão Geral das Semanas

| Semana | Tema Central | Foco Prático |
| :---: | :--- | :--- |
| **01** | **Fundamentos de Teste & Ciclo de Vida** | Base conceitual, validação vs. verificação, tipos de teste, ciclo de defeitos e os 7 princípios de teste. |
| **02** | **Metodologias Ágeis & Casos de Teste** | Dinâmica Scrum e Kanban, histórias de usuário (BDD), técnicas de design de teste (BVA, Partição de Equivalência) e documentação. |
| **03** | **Reporte de Bugs, SQL & Testes de API** | Escrita profissional de bugs, consultas SQL (JOIN, WHERE), arquitetura REST, Postman e scripts de asserção em JavaScript. |
| **04** | **Automação Web (Playwright) & Portfólio** | Automação E2E com Playwright (POM, locatores, asserções), Projeto Integrador, Git/GitHub e preparação para entrevistas. |

## 🚀 Como Utilizar Este Material

1. **Acompanhe o Cronograma:** Acesse [`cronograma.md`](cronograma.md) para conferir a meta e o tópico do dia. Conforme for concluindo os tópicos, marque a caixa de seleção `[x]`.
2. **Consulte os Materiais:** Veja [`recursos.md`](recursos.md) para acessar links diretos para documentações oficiais, tutoriais interativos e ferramentas recomendadas para a semana atual.
3. **Faça Suas Anotações Diárias:** 
   - A pasta [`anotacoes/`](anotacoes/) contém o arquivo [`semana-01.md`](anotacoes/semana-01.md) pré-formatado com seções diárias e retrospectiva.
   - Para as semanas seguintes, basta duplicar o modelo e renomeá-lo para `semana-02.md`, `semana-03.md` e `semana-04.md`.
4. **Construa seu Portfólio:** Guarde no GitHub os artefatos práticos gerados ao longo dos dias (casos de teste documentados, relatórios de bug, coleções do Postman e scripts do Playwright).
